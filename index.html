5. EV Charging Data — OTZOO Energy NEW

OTZOO Energy collects specific data to operate India's unified EV charging ecosystem. This section explains how EV-related data is handled:

5.1 Station Discovery Data

  • EV station data (name, location, connector type, availability) is sourced from Open Charge Map API, Government EV datasets, and host registrations — this is public/aggregated data
  • Your search queries and map interactions are not stored persistently
  • Station availability data syncs weekly from Open Charge Map (Wednesday 2AM IST)

5.2 Booking & Payment Data

  • EV slot bookings are stored with station ID, date, time, duration, amount, and payment status
  • Payment processing is handled by Razorpay/Cashfree — OTZOO does not store payment credentials
  • Booking history is accessible by you in "My Bookings" and retained for 2 years

5.3 Community Verification Data

  • When you submit a station verification (working/broken/queue), your user ID is linked to the verification for reliability score calculation
  • Verification data is displayed anonymously — other users see the result, not your identity
  • False or malicious reports may result in account penalties

5.4 Host Charger Data

  • Your host charger listing (name, location, charger type, price, timing, UPI ID) is publicly visible to EV users on the map
  • Your precise GPS coordinates are stored to accurately display your charger on the map
  • Your UPI ID is stored and used solely for receiving payments from booking users
  • You can deactivate or delete your listing at any time from the Host Dashboard

5.5 Car Verification Data (Private Host Charger Bookings)

  • When booking a private/host charger, you may be required to submit your vehicle registration number and an ID proof type/number
  • This data is encrypted and shared only with the specific charger host for their verification
  • Car verification data is automatically deleted from our servers after 30 days
  • OTZOO does not use car verification data for any other purpose
  • Hosts are prohibited from storing, copying, or misusing this verification data

5.6 OCPI & Beckn Protocol Data

  • OTZOO operates an OCPI 2.2.1 server and Beckn/UEI BAP+BPP server for CPO integrations
  • When CPO partners push station/session data via OCPI, that data is stored in our ev_stations and ev_sessions tables
  • Beckn protocol transaction IDs and session data are logged for debugging and compliance
  • CPO partner credentials (tokens) are stored encrypted and never exposed to end users

⚡ OTZOO Energy is protocol-first: we work with OCPI 2.2.1, Beckn/UEI, and Open Charge Map. No proprietary lock-in. Station data from all sources is merged into one open database and displayed transparently to users.

8. Data Storage & Security

We implement robust technical and organisational measures to protect your data:

  • All data transmission is encrypted using SSL/TLS protocols
  • Authentication is handled via Google OAuth 2.0 — passwords are never stored by Otzoo
  • Database access is governed by Row-Level Security (RLS) policies
  • Growth Partner documents are stored in a private, access-controlled Supabase Storage bucket
  • Payment processing is fully delegated to Razorpay/Cashfree
  • ⚡ EV charging booking data is stored in encrypted Supabase tables with RLS — only you can access your own booking history
  • ⚡ Car verification documents (vehicle number, ID proof) are encrypted and auto-deleted after 30 days
  • ⚡ OCPI partner tokens and Beckn signing keys are stored as encrypted environment variables — never in the database
  • ⚡ Host charger UPI IDs are stored encrypted and displayed only to booking users for payment purposes

⚠️ While we employ industry-standard security measures, no internet-based system is 100% secure. In the event of a data breach, we will notify you as required by applicable law.
